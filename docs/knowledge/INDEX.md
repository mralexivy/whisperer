# Knowledge Index

Domain folders are created on demand as insights emerge. Each folder contains:
- `knowledge.md` — facts and confirmed patterns
- `hypotheses.md` — need more data
- `rules.md` — confirmed, apply by default

## Domains

- [audio/](audio/knowledge.md) — Opus on macOS: which containers Core Audio can actually write, writing real Ogg `.opus` via swift-ogg (libogg/libopus), 16 kHz encoding, why a `.opus` reads back at 48 kHz and `AVAudioFile.read` won't convert for you, frame-exact seeking, crash-truncation survival, the CAF packet-table pad, retention and library compaction ordering, and starting `AVAudioEngine`: why `inputNode` is an unbounded CoreAudio round trip (4.4s measured) and why a wall-clock watchdog over it destroys the start it is supervising ([rules](audio/rules.md))
- [ui/](ui/knowledge.md) — SwiftUI layout gotchas, AppKit (`NSViewRepresentable`) interop, floating always-on-top windows (showing without taking focus, persisting a collapsible window's frame, `NSPanel` vs `NSWindow`, one ownership flag across two surfaces), re-timing batched ASR output into a word-at-a-time stream
- [build/](build/knowledge.md) — the Xcode project uses folder-synchronized groups, so new source files need no `project.pbxproj` edit
- [transcription/](transcription/knowledge.md) — backend chunk cadence, audio-clock timestamps, silence detection, why the stored `language` column is not the transcript's language ([rules](transcription/rules.md))
- [llm/](llm/knowledge.md) — on-device LLM prompting and model selection: output budgets, summary length, fabrication under conditional formats, why MLX cannot load GGUF, why prefill (not parameter count or tok/s) decides wall-clock, how English examples in a prompt override its own "do not translate" rule, why the fix for that failed and an 18-case suite hid it, naming alphabets instead of languages, edit-aggressiveness and translation as one dial, why a prompt tuned on one model inverts on another, the `[INPUT]` echo as in-context format imitation, and how to score a correction prompt (recovery toward authored gold, never against the app's own stored output) ([rules](llm/rules.md), [objective & acceptance criteria](llm/criteria.md))
- [meetings/](meetings/knowledge.md) — model contention at meeting stop, borrowed backends, engine readiness vs. "downloaded" (the one-time Core ML compile), refcounted LLM borrows across a multi-call sequence, LLM KV-cache warmups, session start races, orphaned CoreData rows, RAG index coalescing, post-stop transcript re-transcription (why a second decode beats an LLM rewrite), sentence-validated paragraph breaks (a diarizer-timeline hole reads as silence), waiting for the tail chunk before snapshotting the transcript, per-process mic attribution (a device-level "is running" bit is not attribution), build settings overriding the entitlements file you named, reading crash markers ([rules](meetings/rules.md), [hypotheses](meetings/hypotheses.md))
- [diarization/](diarization/knowledge.md) — Sortformer speaker attribution: accumulated-transcript diffing, finalized-vs-tentative timelines, burst release vs. speech timing, forced-backend lifecycle ([rules](diarization/rules.md))
- [concurrency/](concurrency/knowledge.md) — where code actually runs vs. where its syntax suggests: unannotated `async` closure parameters inheriting the caller's executor (a 40.7s main-thread freeze on opening Meeting Notes), why `Task.detached` and `actor` are both non-guarantees against a `@MainActor` type, isolation inheritance biting only on *synchronous* work, priority not surviving a detach ([rules](concurrency/rules.md))
- [diagnostics/](diagnostics/knowledge.md) — observing the app while it hangs: why `/usr/bin/sample` can never run in the shipped build, in-process main-thread unwind (suspend window, PAC stripping, frame-pointer walk), capturing at detection time rather than after a `@MainActor` hop, reading repeated watchdog alerts as one stall ([rules](diagnostics/rules.md))
