# Knowledge Index

Domain folders are created on demand as insights emerge. Each folder contains:
- `knowledge.md` — facts and confirmed patterns
- `hypotheses.md` — need more data
- `rules.md` — confirmed, apply by default

## Domains

- [audio/](audio/knowledge.md) — Opus on macOS: which containers Core Audio can actually write, writing real Ogg `.opus` via swift-ogg (libogg/libopus), 16 kHz encoding, why a `.opus` reads back at 48 kHz and `AVAudioFile.read` won't convert for you, frame-exact seeking, crash-truncation survival, the CAF packet-table pad, retention and library compaction ordering, and starting `AVAudioEngine`: why `inputNode` is an unbounded CoreAudio round trip (4.4s measured) and why a wall-clock watchdog over it destroys the start it is supervising ([rules](audio/rules.md))
- [ui/](ui/knowledge.md) — SwiftUI layout gotchas, AppKit (`NSViewRepresentable`) interop, floating always-on-top windows (showing without taking focus, persisting a collapsible window's frame, `NSPanel` vs `NSWindow`, one ownership flag across two surfaces), re-timing batched ASR output into a word-at-a-time stream
- [build/](build/knowledge.md) — the Xcode project uses folder-synchronized groups, so new source files need no `project.pbxproj` edit; why a fresh worktree fails at *link* time (`whisper.cpp/build-static` is gitignored) and why nothing GPU- or memory-heavy may run beside an `xcodebuild` ([rules](build/rules.md))
- [transcription/](transcription/knowledge.md) — backend chunk cadence, audio-clock timestamps, silence detection, why the stored `language` column is not the transcript's language, abort granularity being one encoder pass rather than one token (and why that made an abort test unfalsifiable), why an unguarded model warm-up in the test host breaks unrelated timing tests, Core ML/ANE being absent from the whisper path, how badly the stored `language` field mislabels the corpus (151 declared Hebrew, ~10 real), and whisper's language routing differing between a streaming and a whole-file decode of the same audio on 22 of 400 recordings ([rules](transcription/rules.md))
- [llm/](llm/knowledge.md) — on-device LLM prompting and model selection: output budgets, summary length, fabrication under conditional formats, why MLX cannot load GGUF, why prefill (not parameter count or tok/s) decides wall-clock, how English examples in a prompt override its own "do not translate" rule, why the fix for that failed and an 18-case suite hid it, naming alphabets instead of languages, edit-aggressiveness and translation as one dial, why a prompt tuned on one model inverts on another, the `[INPUT]` echo as in-context format imitation, how to score a correction prompt (recovery toward authored gold, never against the app's own stored output), and where batched decode does and does not pay (4.5x aggregate on a 4-bit model, nothing at all mid-stream because chunk arrivals are 6.84s apart, 1.92x on whole-text splitting) ([rounds](../exec-plans/batched-llm-rounds.md), [rules](llm/rules.md), [objective & acceptance criteria](llm/criteria.md))
- [meetings/](meetings/knowledge.md) — model contention at meeting stop, borrowed backends, engine readiness vs. "downloaded" (the one-time Core ML compile), refcounted LLM borrows across a multi-call sequence, LLM KV-cache warmups, session start races, orphaned CoreData rows, RAG index coalescing, post-stop transcript re-transcription (why a second decode beats an LLM rewrite), sentence-validated paragraph breaks (a diarizer-timeline hole reads as silence), waiting for the tail chunk before snapshotting the transcript, per-process mic attribution (a device-level "is running" bit is not attribution), build settings overriding the entitlements file you named, reading crash markers ([rules](meetings/rules.md), [hypotheses](meetings/hypotheses.md))
- [diarization/](diarization/knowledge.md) — Sortformer speaker attribution: accumulated-transcript diffing, finalized-vs-tentative timelines, burst release vs. speech timing, forced-backend lifecycle ([rules](diarization/rules.md))
- [concurrency/](concurrency/knowledge.md) — where code actually runs vs. where its syntax suggests: unannotated `async` closure parameters inheriting the caller's executor (a 40.7s main-thread freeze on opening Meeting Notes), why `Task.detached` and `actor` are both non-guarantees against a `@MainActor` type, isolation inheritance biting only on *synchronous* work, priority not surviving a detach ([rules](concurrency/rules.md))
- [diagnostics/](diagnostics/knowledge.md) — observing the app while it hangs: why `/usr/bin/sample` can never run in the shipped build, in-process main-thread unwind (suspend window, PAC stripping, frame-pointer walk), capturing at detection time rather than after a `@MainActor` hop, reading repeated watchdog alerts as one stall ([rules](diagnostics/rules.md))
- [polishing/](polishing/knowledge.md) — the deterministic transcript editor and the gated generative pass over it: capability tiers (every gate must behave conservatively at `ASRCapabilities = []`, because meetings run on Nemotron and it supplies no evidence), why filler removal must never empty an utterance, diffing an LLM rewrite back into per-token gated edits, protection as a token mask rather than sentinel substitution, and the measured edit rates over 18,099 real words ([rules](polishing/rules.md))
- [benchmarking/](benchmarking/knowledge.md) — measuring a change on the user's own recordings: why a same-model decode bounds damage but cannot score recovery (median headroom 0.038), the two label defects in this corpus, and the shape of an A/B against a shipped path — real stored output as the control, paired rows, verdict rule fixed first, a loud failure when the corpus does not load ([rules](benchmarking/rules.md))
